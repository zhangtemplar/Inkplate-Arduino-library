# Inkplate 13SPECTRA Digital Picture Frame

This project turns Inkplate 13SPECTRA into an SD-backed photo frame with optional web syncing and a browser configuration UI.

## SD Card Layout

Format the SD card as FAT/FAT32. The sketch creates these paths automatically:

- `/frame/config.json` for settings
- `/frame/photos/` for local photos
- `/frame/config_mode.txt` as an optional boot trigger for config mode

Supported local image types are `.bin`, `.jpg`, `.jpeg`, `.png`, and `.bmp`. JPG, PNG, BMP, and converter-generated BIN files automatically use landscape or portrait orientation based on image aspect ratio. For best quality, use `.bin` files generated by `tools/convert_to_inkplate13spectra_bin.py`.

## Google Drive Folder Sync

The frame syncs from a Google Drive folder through the included `google_drive_apps_script.gs` web app. The Drive folder can stay private; the Apps Script runs as your Google account and the Inkplate authenticates with a shared token.

1. Create a Google Drive folder for frame photos.
2. Open Apps Script, paste `google_drive_apps_script.gs`, and set `FOLDER_ID` plus `SYNC_TOKEN`.
3. In the Apps Script editor, select `manifestOutput` and click Run once. Grant the requested Drive permissions as the script owner.
4. Deploy it as a web app with "Execute as: Me" and "Who has access: Anyone with the link".
5. Test the deployed `/exec` URL, not the editor-only `/dev` URL, plus `?mode=manifest&token=SECRET` in a private browser window. It must return JSON without a Google login, permission grant, or popup.
6. Enter the web app `/exec` URL and the same token on the frame config page.

If the test URL asks for Google authorization, the deployment is not usable by the Inkplate. Recheck that the web app runs as you, that access is public/link-based, and that you created a new deployment version after editing the script. Some Google Workspace domains block public Apps Script web apps; in that case use a personal Google account or a different manifest host.

The Apps Script exposes:

```text
?mode=manifest&token=SECRET
?mode=file&id=DRIVE_FILE_ID&token=SECRET
```

The manifest includes `id`, `name`, `modified`, and `size`. The Inkplate saves `/frame/sync_state.json` and downloads only missing or changed files. The config page controls how often the frame checks Drive; set "Sync every display updates" to `1` to check on every wake. Keep the Drive sync folder focused; the example processes up to 48 supported files and uses a 60 second HTTP read timeout for Apps Script cold starts.

## Config Mode

On first boot, the frame starts an access point named `Inkplate13Frame` with password `inkplate13`. Open the IP shown on the display, usually `http://192.168.4.1`. Configure Wi-Fi, Apps Script URL, sync token, sync cadence, photo folder, shuffle mode, update interval, and low-battery threshold. After Wi-Fi is configured, config mode first tries the home network and disables the setup AP when the connection works; the display shows the home-network URL. If Wi-Fi is missing or fails, the fallback AP is enabled again.

To force config mode later, press the Inkplate 13SPECTRA WAKE button while the frame is sleeping; the sketch enables GPIO18 as a config-mode wake source. While config mode is running, press WAKE again to close the web UI and return to photo display mode. You can also create an empty file at `/frame/config_mode.txt`. The library does not expose a clear USB/VBUS detect pin for this board; if your hardware revision exposes one, set `USB_POWER_DETECT_PIN` near the top of the sketch so USB power automatically enters config mode.

The config page shows the tail of `/frame/sync_debug.log`, and the same debug lines are printed to Serial at 115200 baud. Open `/log` for the full recent sync log and `/manifest_response` for the raw response captured from the last manifest request. Tokens are redacted from logged URLs. The "Sync photos now" button queues sync and returns immediately; while sync runs, `/log` remains available and SD-mutating commands are rejected until sync completes.

In normal frame mode, the sketch displays a local photo first, then runs scheduled sync with that photo left on the e-paper panel. If no local photos exist yet, it may sync before the first photo display.

## File Management

The config page includes an SD file manager scoped to the configured photo folder. Use it to upload `.bin`, `.jpg`, `.jpeg`, `.png`, or `.bmp` images, create subfolders, delete individual image files, and recursively delete subfolders. Photo playback scans subfolders too. Deleting the photo root itself is blocked so settings and sync state stay intact.

## BIN Conversion

Install Pillow, then convert images:

```sh
pip3 install Pillow
python3 tools/convert_to_inkplate13spectra_bin.py photo.jpg /Volumes/SDCARD/frame/photos/photo.bin --preview photo_preview.png
```

The converter defaults to `--orientation auto`, using a 1600x1200 landscape canvas for wide images and a 1200x1600 portrait canvas for tall images. Override with `--orientation landscape` or `--orientation portrait` when you want a fixed layout. It dithers into the six Spectra colors, then stores the packed native framebuffer for fast, high-quality display.
